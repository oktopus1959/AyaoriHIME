# ADR: 交ぜ書き辞書における MAZE エントリの候補グループ優先

## 日付
2026-08-17

## 背景
- 交ぜ書き辞書の前処理は、通常エントリと末尾に `MAZE` を持つ交ぜ書きエントリを同じ出力集合に保持する。
- 見出し語だけが同じ通常エントリと MAZE エントリを単純に隣接比較して通常行を除外すると、接続 ID や品詞が異なる別語まで失われる。例として、`する` の通常エントリと `摩る` から生成された `する` の MAZE エントリは、見出し語が同じでも左・右接続 ID が異なる。
- 一方、同じ辞書候補に対応する通常エントリと MAZE エントリでは、変換基本形・変換表層形が異なることが正しい。この差を一致条件に含めると、通常エントリを除外できない。
- `linesMap` は `std::map` であり、出力順は入力順ではなくキー順で決まる。コストなどの値により MAZE 行が通常行より先に並ぶため、直後の行だけを比較する方式は成立しない。

## 決定
- `MazegakiPreprocessor::output()` は、MAZE 行を収集する走査と出力する走査の二段階で処理する。
- 判定対象は `main()` が生成する出力形式だけとする。通常行は8項目、MAZE 行は9項目かつ最終項目が厳密に `MAZE` でなければならない。
- 候補グループは、次の5項目で識別する。

  ```text
  見出し語, 左接続ID, 右接続ID, 品詞:細品詞, 交ぜ基本形
  items[0], items[1], items[2], items[4], items[5]
  ```

- 候補グループごとに MAZE 行の最小コストを求める。その最小コストが通常行コストから 2000 を引いた値以下の場合にだけ、同じ候補グループの通常行を出力しない。MAZE 行は常に出力する。
- 除外した通常行は、辞書生成時に追跡できるよう標準エラーへそのまま1行出力する。
- `items[6]`（変換基本形）および `items[7]`（変換表層形）は候補グループの識別に使用しない。
- 任意形式の原文行は判定対象外として、従来どおり出力する。

## 影響
- `する` の通常行と、異なる接続 ID を持つ `する` の MAZE 行は共存する。
- 同じ接続 ID・品詞・交ぜ基本形を持つ「あいがん」の通常行は、対応 MAZE 行が 2000 以上低コストの場合に除外され、標準エラーへ記録される。
- 同じ候補グループでも、通常の「なる」が 5063、`成る` 由来の MAZE 行が 7182 の場合は通常行を保持する。
- `摑みどころ` と `摑み所` のコストが同値の場合は、通常行を保持する。
- MAZE 行の有無による通常行の出力可否は、入力順および `std::map` のキー順に依存しない。

## 確認
- `bin/Release/dymaz.exe expand DyMazin/foo.csv` により、通常の「なる」が 5063、対応する MAZE 行が 7182 の場合に、通常行と MAZE 行がともに標準出力へ出ることを確認した。
- 一時辞書ファイルで「あいがん」の通常行1件と MAZE 行3件を与え、MAZE 行3件だけが標準出力へ出て、通常行が標準エラーへ出ることを確認した。
- 一時辞書ファイルで `摑みどころ` と `摑み所` を与え、同コストのため `摑みどころ` の通常行が標準出力に残ることを確認した。
- DyMazinLib Win32 Release のビルドが警告・エラーなしで完了することを確認した。
